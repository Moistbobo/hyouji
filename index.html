hyouji 表示

Preview HTML files stored in GitHub Gists

Usage

https://www.hyouji.moe/?gist=<url to your gist>

Features

  • Load any public GitHub Gist containing HTML files.
  • Render the HTML in a sandboxed iframe in your browser.
  • Toggle script execution for interactive demos.
  • Share previews by copying a single URL.

hyouji loads HTML from public GitHub Gists and renders it in a sandboxed iframe.
